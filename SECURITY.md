# Security

This is an early prototype. Run against disposable or explicitly authorized test data.
Do not publish secrets or sensitive logs in issues or report artifacts.
If a security issue exposes data, report it privately to syedfarhan6669@gmail.com with
a synthetic reproduction. There is no guaranteed response time or paid bounty.

Reports are summaries, not proof that data is anonymized or that a detection policy is safe.
Review artifacts before sharing. Python reads supplied JSON; it does not execute input as code.
HTML escapes untrusted content and does not load remote scripts or assets.
